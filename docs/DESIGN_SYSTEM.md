## 命名样式(随叫随取)

### 🟡「星愿金卡」Aurum — class `.fx-aurum`
- **来历**:连续打卡里程碑 21 天英雄级弹窗那张卡。
- **长相**:深紫底 + 顶部一圈金色光晕 + 金色描边 + 金色柔光投影。高级、有"奖杯感"。
- **配套**:`.fx-aurum-pill` = 金色渐变胶囊/徽章(`#ffd86b→#ffb347` + 深字 `#1a1426`),用于"习惯养成""英雄级"这类高光标签。
- **用在**:重要成就、里程碑、最高级奖励、想让人"哇"一下的卡片。

### 🔥「火苗卡」Ember — class `.fx-ember`
- **来历**:签到页"连续签到"Hero 卡 + 本周完成那块。
- **长相**:左上角一团暖橙火光晕,像"一团火点亮了整张卡",底色金色微渐变。
- **用在**:连续/坚持/热度相关的卡(streak、火花、热力)。常和大火苗 🔥 一起用。

### 💛「呼吸光圈」Breath Halo — class `.fx-breath`
- **来历**:里程碑路线图"当前进行中"那个金色小圆点。
- **长相**:金色光圈一缩一放的脉冲呼吸,温柔地提示"这里是当前/进行中"。
- **用在**:当前节点、待办高亮、"该你了"的提示点。

### 🔥「火苗跳动」Flame Bob — class `.fx-flamebob`
- **来历**:连续签到大火苗 🔥 的轻轻上跳 + 放大 + 暖光投影。
- **用在**:火焰/能量类图标,让它"活"起来。

> 都自带 `prefers-reduced-motion` 关闭动效兜底。

## 南哥的审美偏好画像(我据历次修改总结,用来更懂你)

**他喜欢我重点探索/打磨的部分:**
1. **可视化代替纯文字** —— 文字单调,要图表、卡片、状态徽章、进度条、镜像视图(如家长端「看星晨」)。
2. **连续性/坚持的游戏化反馈** —— 像抖音好友"火花"、多邻国 streak:连续越久越有"火",要明显、要有盼头、要追求单项连续性。
3. **金色高级感 + 渐变光晕** —— 金色(`#ffd86b/#ffb347`)、顶部/角落光晕、"点亮整张卡"的感觉。
4. **微动效/呼吸/脉冲** —— 当前节点的呼吸光圈、火苗跳动、粒子飞舞(利息),细腻但不吵。
5. **日历/打卡可视化** —— 热力月历、单项打卡的连续天数、火花,样式要"足够好看"。
6. **对齐/排版精致** —— 数字对齐、卡片同高、图标统一(SVG > 粗糙 emoji)。
7. **每步看得见、上线验证** —— 不要看不见的后台活;要能在手机上立刻看到效果。

**他不喜欢:** 纯文字堆砌、单调、鸡毛蒜皮表面功夫、看不见的改动、糊弄。

> 一句话:**把"坚持"做得像游戏一样诱人、把每个状态做得好看可视、用金色+火+光晕+呼吸营造高级感。**
