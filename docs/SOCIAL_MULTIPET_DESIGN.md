# 星晨成长日记 · 多宠物类型 + 多人社交版 设计方案

> 状态:**设计稿,不急着做**。落地顺序见文末"优先级"。
> 一句话愿景:从"一个孩子的成长日记",长成"一群同学一起坚持打卡、各养各的宠物、互相激励"的安全小社区。家长始终是审核者。

---

## 一、多宠物类型(社交版的前置基础,可先做)

### 现状
单一物种「星愿犬」,一条 15 形态进化线(egg→…→星愿神犬)。

### 目标
不能全是狗狗。引入"物种(species)"维度,每个物种有**自己的一条进化线**,孩子能拥有不同的宠物;同学之间物种不同,社交时更有趣。

### 候选物种(统一 Q 版国风/梦幻画风,保持系列感)
| 物种 | 卖点 | 风格关键词 |
|---|---|---|
| 🐉 星愿龙 | 帅气国风祥龙,男生也爱 | 祥云、鳞光、威严又萌 |
| 🐱 星愿猫 | 灵动可爱,女生缘高 | 铃铛、灵动大眼 |
| 🦊 星愿狐 | 九尾灵狐,国风仙气 | 九尾、符箓、仙灵 |
| 🐰 星愿兔 | 月宫玉兔,温柔 | 月亮、捣药、软萌 |
| 🐼 星愿猫熊 | 国宝,憨态 | 竹子、圆滚滚 |
| 🦄 独角兽/飞马 | 纯梦幻 | 彩虹、星河、翅膀 |

### 实现思路(改动可控)
- 数据:`pet.species` 字段决定用哪条进化线。把现在的单一 `FORMS` 数组重构成 `SPECIES = { dog:{name,forms:[...]}, dragon:{...}, ... }`,`petConfig` 按 `pet.species` 取对应 forms;`effectiveStage`/`tierFromLevel` 逻辑复用,不动。
- 选择:**孵化前选蛋**——不同蛋孵不同物种。首发送 1~2 个物种免费,其余用星币 / 里程碑解锁"新物种蛋"(给收集和长线目标)。
- 美术节流:每个新物种**先做 egg + 3~5 个关键形态**(而不是一上来 15 个),进化线后续逐步补;缺图回落到该物种已有形态(沿用现有 fallback 机制)。
- 即梦:同一画风出图,保证系列一致;先出"基础形态"立绘,跑通再补进化与动画。

> 估算:每物种 ≈ 4~6 张图 + 2 段动画起步。即梦 credits 够,逐物种来。

## 二、多人社交版

### 角色与关系
- **孩子(同学们)**:各自打卡、养各自的宠物。
- **家长(各自的爸妈)**:只审核/评价**自己孩子**的打卡、发奖励。
- **关系**:同学之间是"好友/同班",可**看**彼此宠物、**有限互动**,但**不能改**对方任何数据。

### 关键:数据模型 & 安全(这是版本级重构,最重投入)
现状是**单一 `xc_state` 行 + localStorage**,全家共享一份。多人必须升级为真正的多用户后端:
- 每个家庭/孩子一份**独立 state**(按 account/family 维度隔离)。
- 新增表:`families`(家庭账号)、`friendships`(好友/同班关系)、`interactions`(宠物互动事件)。
- **RLS 权限红线(儿童产品安全第一)**:
  - 孩子只能改自己的数据;
  - 家长只能审核**自己孩子**的打卡;
  - 好友只能**只读 + 有限互动**(点赞/拜访/送礼),**绝不能**改对方数据或看敏感信息;
  - **无陌生人社交**:加入只能通过"班级码/好友码",且**必须家长参与建号**。

### 加入流程(同学 + 其家长一起进来)
1. 星晨在 App 生成**邀请码/邀请链接**(好友码或班级码)。
2. 同学打开 → 注册:**由其家长创建账号**、绑定孩子、设家庭密码(孩子不能独自注册)。
3. 同学**选蛋孵化**自己的宠物 → 开始打卡。
4. 同学的家长在**自己的家长端**审核同学的打卡(与现在星晨家长端一致)。

### 宠物互动玩法(分阶段开放,先轻后重)
**阶段 1 · 轻互动(只读 + 点赞,安全简单)**
- 好友列表:看同学的宠物、等级、连签天数。
- 串门拜访:进同学的宠物窝看看,留个"赞"或鼓励贴纸。
- 坚持小组榜:班级连签榜/本周打卡榜——**弱化排名压力**,做成"坚持小组"正向激励,而非高低竞争。

**阶段 2 · 协作**
- 组队坚持:几个同学组"坚持小队",共同目标(本周全队都打卡)→ 解锁团队奖励。
- 互相送礼:用星币给同学宠物送小零食 → 触发对方宠物开心动画。
- 宠物合影:两只宠物同框,生成图分享。

**阶段 3 · 深度玩法**
- 宠物切磋(非暴力):基于属性的"智慧问答""运动小游戏"PK。
- 全班副本:共同大目标(如"全班累计 1000 次打卡")解锁全班奖励。
- 物种互动彩蛋:不同物种之间有专属互动小动画。

### 合规提醒(儿童社交,必须守)
依《儿童个人信息网络保护规定》:家长知情同意、数据最小化、无开放注册/陌生人社交、内容可审核。**先在星晨的几个同班好友里小范围灰度,不做公开注册。**

## 三、落地优先级建议

| 级别 | 事项 | 依赖 | 说明 |
|---|---|---|---|
| **P0** | 多宠物类型(选蛋孵化不同物种) | 无(纯前端+即梦出图) | 社交版前提,现在就能逐步做 |
| **P1** | 多用户后端重构(Supabase 多账户 + RLS) | — | 社交版**地基**,最重的一块 |
| **P2** | 邀请加入流程 + 好友列表 + 轻互动(看/赞/拜访) | P1 | 社交"能用"的最小闭环 |
| **P3** | 组队坚持 / 送礼 / 坚持小组榜 | P2 | 协作与激励 |
| **P4** | 宠物 PK / 全班副本 / 物种彩蛋 | P3 | 深度玩法,长期 |

**结论**:多宠物类型(P0)先做、可逐物种推进;社交版从 P1 的数据/权限地基起步,体量大、慎重灰度。等南哥拍板再排期。
